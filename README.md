## Safety rules

- Do not commit `.env`, `.env.local`, tokens, anon keys, service role keys, or database passwords.
- Do not print secret values in chat/log summaries.
- Do not run destructive commands against the remote project without explicit approval.
- Safe local commands: `supabase start`, `supabase status`, `supabase stop`.
- Remote-affecting commands like `supabase db push`, `supabase migration up --linked`, deletes, resets, or production data changes require explicit approval.

## Authentication needed for cloud link

The local stack is running, but the cloud project is not linked until Supabase CLI auth is completed locally.

Preferred safe auth flow:

```bash
supabase login
```

Then link:

```bash
supabase link --project-ref itraeknotcdtdzaeukan
```

If the CLI asks for the remote database password, enter it locally. Do not paste it into chat.
